NASIR BIN ALI AL-KUWARI & SONS GARAGE - GITHUB PAGES DEPLOYMENT

1. Open the GitHub repository that publishes nasirqtr.github.io.
2. Replace index.html and style.css in the same directory as the currently published index.html.
3. Replace the assets/ folder (including garage-gate-entry.webp).
4. Keep script.js alongside index.html. Do NOT upload the ZIP itself to GitHub Pages. Upload its extracted contents.
5. Commit your changes, then open https://nasirqtr.github.io/#location in a private tab.
6. Use Open Maps / Get Directions to confirm the garage listing and drive destination.

The interactive map is the Yandex Maps business widget for Nasser bin Ali Al Kuwari Garage (Street 19, Industrial Area). The old Google iframe that displayed a world map has been replaced. Google Maps links remain for navigation. Please check the live marker after deployment. To embed Google Maps itself, use the official Share > Embed a map code or a Maps Embed API key.

The booking/quote forms require a configured Cloudflare Worker, Turnstile keys and D1 database. The static site alone cannot store requests.
